# Marca para icono e inicio

La imagen aportada por el usuario se usó como referencia de edición para el recorte con transparencia mediante la herramienta integrada `image_gen`.

Master: `dinoxo_store_badge_master.png`. Recurso Flutter: `assets/images/dinoxo_store_badge.png`. El script `tool/prepare_brand_assets.ps1` solo prepara tamaños y márgenes de los recursos Android a partir del master; no vuelve a generar el diseño.

Prompt de edición: extraer únicamente el medallón circular completo del logo adjunto, eliminando el fondo rectangular exterior a transparencia real. Conservar el emblema metálico del dinosaurio, la cara negra texturizada, el borde metálico y cian, el ojo azul y la inscripción exacta «dinoxo.Store». Mantener todo el círculo visible y centrado, sin recortar letras ni añadir elementos.
